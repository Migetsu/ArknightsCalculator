# Дизайн-система: «Ember Editorial» (направление C)

Источник истины по внешнему виду: HTML-макеты в `docs/design/mockups/` (открываются в браузере, нужен интернет для шрифтов). Точные значения (цвета, размеры, отступы) берутся из CSS внутри макетов. При расхождении между этим файлом и макетом побеждает макет, расхождение записывается в `docs/known-issues.md`. Данные в макетах (имена, числа, даты, `[скобки]`) являются заглушками: в код они не переносятся, всё берётся из данных проекта и i18n.

## Настроение

Тёмный, мрачный, слегка загадочный интерфейс по духу Arknights, но с абсолютно понятным управлением: одно главное действие на экран, чёткая навигация, видимое активное состояние, пустые состояния с подсказкой. Загадочность создаётся атмосферой (свечение, подписи вида `TERMINAL // ...`), а не запутанностью.

## Токены

Цвета (CSS-переменные и SCSS-переменные, хардкод в компонентах запрещён):

- Фон страницы: `#0e0a09` + радиальное свечение `radial-gradient(ellipse at 80% 0, #2a1510 0, #0e0a09 55%)`.
- Поверхность панели: `#17110f`. Глубокая поверхность (поля, ячейки): `#0e0a09`.
- Линии: `rgba(232,221,211,.08)` (панели), `.12` (разделители), `.15–.2` (поля, кнопки).
- Текст основной `#e8ddd3`, приглушённый `#a8978a` (на тёмном проверять контраст AA), светлый акцентный текст/подписи `#ffd9a8`.
- Акцент ember `#ff6a3d` (только главная кнопка, активный пункт навигации, выбранные чипы, ползунки, прогресс); ember-светлый `#ff8a5c` (дефицит, ссылки); янтарь `#ff9d2b` (предупреждения, редкость 6★); успех `#8fd19e`; текст на ember-фоне `#120d0b`.
- Редкость: 6★ `#ff9d2b`, 5★ `#ffd54f`, 4★ `#9b6bd6`, 3★ `#6fa3e0`, 2★ `#7fc48a`, 1★ `#8a8a8a`.
- Тиры предметов (рамка иконки): T1 `#8a8a8a`, T2 `#7fc48a`, T3 `#6fa3e0`, T4 `#a97be0`, T5 `#e0b44a`.
  Типографика (самохостинг через @nuxt/fonts, обязательна кириллица): заголовки и крупные числа `Unbounded` 800, текст и подписи `Golos Text` 400/600. Заменяют прежние Exo 2, Inter, JetBrains Mono. Размеры: h1 34–44px, h2 15–18px, подписи 11–13px UPPERCASE с letter-spacing .12–.2em, текст 14–16px, минимум 12px.
  Форма: без скруглений (0–2px), рамки 1px, плоские панели, без косых кнопок и срезанных углов (прежняя система clip-path/skew убирается). Сетка: отступы страницы 36px 48px (мобильные 16px), зазоры 20–28px, максимальная ширина контента 1440px по центру.

## Компоненты (переписать под ui/Ak*, с тестами и витриной _ui.vue)

- AkHeader: логотип, навигация (Home, Operators, Planner, Depot, Farming, Recruit, Gacha), справа ссылка Settings. Активный пункт: цвет `#ffd9a8` + подчёркивание 2px ember. На мобильных меню-drawer. Переключателя языка в шапке НЕТ.
- AkPanel (.pn), AkButton (primary ember / outline / gold-outline `rgba(255,217,168,.4)` / danger), AkChip (переключаемый тег, включён = ember), AkSegmented (язык, сервер, режимы), AkTabs (кнопки: активная ember, остальные outline; на странице оператора вариант с подчёркиванием), AkStat (плитка метка+значение), AkStepper (поле числа с кнопками − и +, нативные стрелки number скрыты, фокус виден), AkInput, AkProgress, AkAlert (янтарь), AkEmptyState (пунктир), AkModal (левая полоса 4px ember).
- Иконки и картинки (везде настоящие, не текст): AkAvatar (размеры 44/48/52/56/64/84, нижняя линия 3px цвета редкости, fallback инициалы), AkItemIcon (рамка цвета тира, бейдж количества), AkSkillIcon (круг 48px, золотая рамка), AkModuleIcon (ромб, рамка ember). Источник картинок только `resolveAsset()`.

## Правила

- Строки только через i18n (en, ru по отдельности). Русские надписи длиннее на 20–30%: проверить переносы и переполнение.
- Мобильные раскладки макетов не содержат: выводятся по правилам AGENTS.md (одна колонка, drawer, 360px), без горизонтального скролла.
- Состояния загрузки, пусто, ошибка обязательны на каждой странице.
- Арт баннеров и персонажей: сначала проверить источник и права, никакого хотлинка на prts.wiki; при отсутствии арта показывать градиентную заглушку.
- Любое отклонение от макета фиксировать в `docs/known-issues.md`.
