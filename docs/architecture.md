# Architecture Overview

## 1. Technology Stack

- **Framework:** Nuxt 4 (Vue 3, Composition API, `<script setup lang="ts">`)
- **Language:** TypeScript (`strict: true`, `noUncheckedIndexedAccess: true`)
- **State Management:** Pinia (`@pinia/nuxt`)
- **Composables:** `@vueuse/core` (`@vueuse/nuxt`)
- **Styling:** SCSS + BEM methodology (no UI component libraries)
- **Icons & Images:** `@nuxt/icon`, `@nuxt/image`
- **Backend / Database:** Supabase (Client: `@nuxtjs/supabase`, RLS-enabled, stateless proxy for secure integrations)
- **Localization:** `@nuxtjs/i18n` (en/ru, planned)
- **Testing:** Vitest (`@nuxt/test-utils`), Playwright (Chromium)
- **Deployment:** Vercel (CI via GitHub Actions)

## 2. Directory Structure (Nuxt 4)

```text
app/            pages/, components/, composables/, stores/, utils/, assets/styles/, layouts/, plugins/
server/         api/ (Nitro proxies and secret handling), utils/
shared/         types and pure functions shared between app and server
data/           generated JSON (game data, banners, penguin benchmark)
scripts/        data sync and build scripts (Node.js/Actions)
tests/          unit/, e2e/
docs/           architectural decisions, module guides, progress tracking
```

## 3. Core Principles

- **Calculation Core:** Pure TypeScript functions in `shared/` without Vue/Pinia/network dependencies, covered by unit tests.
- **External Data:** Validated via Zod schemas; runtime game data pre-generated by offline scripts in `data/`.
- **Offline / PWA:** Planner, depot, farming, and gacha tools designed for offline client-side functionality.
- **Zero Server Cost:** Serverless Nitro functions only for CORS proxies and secret handling.

## 4. Testing

### Structure

- `tests/unit/`: Unit tests for pure business logic, calculations, and components.
  - Tests for `shared/` run in lightweight `node` environment without Nuxt overhead.
  - Component tests run in `nuxt` environment with `happy-dom` via `@nuxt/test-utils`.
- `tests/e2e/`: End-to-end tests using Playwright (Chromium).

### Running Tests

- `npm test`: Run all unit tests with Vitest (`vitest run`).
- `npm run test:watch`: Run unit tests in watch mode (`vitest`).
- `npm run test:e2e`: Run Playwright e2e tests (`playwright test`).

### Guidelines

- All calculation core modules in `shared/` must be thoroughly covered by unit tests.
- E2E tests focus on critical user flows (smoke tests, navigation, core workflows).
